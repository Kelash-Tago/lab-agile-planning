# Lab Agile Planning

## 📌 Description
This lab is a practical application of the **Scrum methodology** in Software Engineering.  
It focuses on understanding how agile planning works using real project management steps.

---

## 🎯 Objectives
- Understand Scrum and Agile planning concepts
- Learn how to manage work using issues and backlogs
- Practice task tracking from start to completion

---

## 🛠️ What We Did in This Lab
- Created issues for project tasks  
- Added tasks to the product backlog  
- Selected tasks for implementation  
- Moved tasks through workflow stages (To Do → In Progress → Done)  
- Reviewed completed tasks  

---

## 📚 Technologies / Tools Used
- GitHub Projects
- GitHub Issues
- Scrum / Agile Methodology
